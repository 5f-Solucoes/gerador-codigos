1. VISÃO GERAL
================================================================================
O Gerador de Códigos é uma aplicação desenvolvida para automatizar a geração
de códigos e sequências alfanuméricas com diferentes padrões e configurações.

Versão: 1.0.0
Linguagem Principal: JavaScript/TypeScript
Framework: Node.js / Express
Banco de Dados: MySQL/PostgreSQL
Status: Em Desenvolvimento (branch: develop)


2. ARQUITETURA DO PROJETO
================================================================================
O projeto segue uma arquitetura modular com as seguintes camadas:

├── /src
│   ├── controllers/       - Lógica de negócio e manipulação de requisições
│   ├── models/           - Modelos de dados e banco de dados
│   ├── routes/           - Definição de rotas da API
│   ├── services/         - Serviços reutilizáveis
│   ├── utils/            - Funções utilitárias
│   └── middleware/       - Middlewares customizados
├── /tests               - Testes unitários e integração
├── /docs                - Documentação
└── /config              - Arquivos de configuração


3. DEPENDÊNCIAS PRINCIPAIS
================================================================================
- express: Framework web
- dotenv: Gerenciamento de variáveis de ambiente

5. ENDPOINTS PRINCIPAIS
================================================================================

GET /api/codigos
- Descrição: Listar todos os códigos gerados
- Autenticação: JWT
- Response: { codigos: [], total: number }

POST /api/codigos/gerar
- Descrição: Gerar novo código
- Autenticação: JWT
- Body: { tipo: string, quantidade: number, prefixo?: string }
- Response: { codigo: string, dataGeracao: date }

GET /api/codigos/:id
- Descrição: Obter detalhes de um código específico
- Autenticação: JWT

DELETE /api/codigos/:id
- Descrição: Deletar um código
- Autenticação: JWT


6. FLUXO DE AUTENTICAÇÃO
================================================================================
1. Usuário realiza login com credentials (POST /auth/login)
2. Servidor retorna JWT token
3. Cliente armazena token no localStorage
4. Token é enviado no header Authorization: Bearer <token>
5. Middleware valida token em cada requisição protegida

10. TROUBLESHOOTING
================================================================================
Erro: "Database connection failed"
- Verificar credenciais em .env
- Confirmar se MySQL/PostgreSQL está rodando
- Verificar firewall

Erro: "JWT token invalid"
- Fazer novo login
- Verificar JWT_SECRET em .env

Erro: "CORS error"
- Adicionar origem em whitelist no middleware CORS
